# Blockiva: Block Puzzle

**Tagline:** Place. Clear. Combo.

Blockiva is an original offline-first 8×8 block puzzle built with Flutter/Dart. The codebase is structured for production gameplay, persistence, rewarded revive, coins, themes, daily challenges, analytics and future monetization without coupling ads to the game engine.

## Development status

Active development on `main`.

## Run

```bash
flutter pub get
flutter run
```
